# CastReader 指读实验：人工测试

## 当前交付状态

这是**独立桌面同步内核实验**，不是已完成的 Codex 原回答功能。它不会读取或修改 Codex，不是要求用户接受的替代阅读面板。市场中的 0.1.2 仍是语音开发/音频生成版；本次没有提交原回答指读新版。

同步内核已修复并通过 14 项桌面测试。原回答 DOM 适配、会员登录与权益、中文真实词级对齐及长回答验收尚未完成。因此最终插件还不能交付安装验收。

## 在这台 Mac 上查看内核实验

Finder 中双击本目录 `launch.command`。它仅打开已经准备好的 Electron 实验和本地音频，不请求 API、不扣费。其他机器需要按 README 准备运行环境，不能直接依赖这台机器的缓存。

1. 点击“停止并清除”，再点“播放指读”：音频从头播放，高亮依照实际时间戳推进。
2. 点击暂停：声音停止，词高亮应停在当前播放位置。
3. 恢复播放并选择 1.5× 或 2×：观察高亮是否仍跟随声音。
4. 拖动播放器时间条或“跳到 ideas”：核对指向位置；静音空隙应没有词高亮。
5. 点击“停止并清除”：音频回到开头，高亮清除且不会自行再次出现；再播放应恢复。
6. 移动、缩放窗口，观察链接/加粗文字处是否仍定位准确。听感是否提前/滞后需人工判断，自动通过不替代听感验收。

素材是此前真实生成的 4.968 秒英文 CastReader WAV，共 8 个真实词时间戳。它不能验证中文、长文或会员链路。
